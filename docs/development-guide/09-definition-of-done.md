# Definition of Done

Kartu selesai bila semua butir di [team-and-process](../task-breakdown/team-and-process.md) bagian 5 terpenuhi:

- AC tanpa regresi.
- Lint dan tipe bersih.
- Tes sesuai jenis kartu.
- Tracker API `OK` untuk operasi kartu.
- PR sesuai higiene.
- Lead-review tiga ronde disetujui.
- THEN-clause terbukti.
- Teks UI persis AC.
- Item SEC-NN yang berlaku lulus checklist biner.
