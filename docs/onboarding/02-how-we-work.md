# How We Work

Tim: TL, BE1, FE1. PIC per kartu tercantum pada kolom Owner di [task breakdown](../task-breakdown/sprint-1.md); dokumen teknis lain menggunakan peran (P-07).

- Satu kartu = satu PR.
- Contract-first.
- Lead-review tiga ronde oleh TL.
- PR milik TL direview BE1 atau FE1 sesuai area `[ASSUMED Q-37]`.
- Rundown PM memakai satu sprint. Kapasitas dihitung dari 5 hari kerja × 5,5 jam efektif × jumlah developer; jumlah developer dan scope committed belum ditetapkan. Estimasi 8 dev-day/engineer dan risiko FE 109% berasal dari rencana 3-sprint lama, bukan kapasitas aktif. Lihat [rundown PM](../decisions/2026-11-08-pm-sprint-timeline.md).

Kartu ada di [task-breakdown](../task-breakdown/_index.md). Jangan menambah AC ID di dokumen bisnis.
